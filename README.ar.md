# Claude Window Pinger

[English](README.md)

أداة تبدأ نافذة استخدام Claude التالية (الخمس ساعات) تلقائيًا فور انتهاء النافذة الحالية.

تحسب اشتراكات Claude الاستخدام في نوافذ مدتها 5 ساعات، ولا تبدأ النافذة الجديدة إلا عند إرسال رسالة. ترسل هذه الأداة رسالة صغيرة جدًا عبر [Claude Code](https://code.claude.com/docs) الرسمي بعد كل إعادة تعيين، فيكون العدّ قد بدأ قبل أن تجلس للعمل.

> **الأداة لا تزيد حصتك.** هي تبدأ العدّ مبكرًا فقط، فتتجدد حصتك أسرع. إذا بدأت العمل بعد ساعتين من البينج، تتجدد حصتك بعد 3 ساعات بدل 5.

هذا مشروع مستقل، ولا علاقة له بشركة Anthropic ولا تدعمه.

## طريقة العمل

- **نحو 5 بينجات في اليوم:** تعتمد على موعد إعادة التعيين الذي يذكره CLI، ولا تخمّن. وإذا بدأت النافذة بنفسك، تنتظر حتى تنتهي.
- **استهلاك ضئيل جدًا:** يستخدم كل بينج `claude-haiku-5-5` بجهد `low`، بلا أدوات أو خوادم MCP أو سجل محادثة، أي نحو 600 توكن إدخال و4 توكنات إخراج.
- **CLI الرسمي فقط:** لا تقرأ توكناتك ولا تستخدم واجهات خاصة.
- **بلا اعتماديات:** سكربت Python 3 واحد يستخدم المكتبة القياسية فقط.

## قبل الاستخدام

- **راجع الشروط بنفسك:** شروط Anthropic تقيّد الوصول الآلي عمومًا. وضع `claude -p` ميزة رسمية، لكن هذا المشروع لا يدّعي أن هذا الاستخدام تحديدًا مسموح، وحسابك مسؤوليتك.
- **نسخة واحدة لكل حساب:** الحد مرتبط بالحساب، فلا فائدة من جهاز ثانٍ.
- **يجب أن يكون الجهاز شغالًا:** بعد السكون أو الإطفاء، يُرسل البينج عند عودة الجهاز وليس في موعده.

## المتطلبات

- Linux مع systemd وPython 3.9 أو أحدث
- باقة Claude مدفوعة تشمل Claude Code

## التثبيت على جهاز شخصي

تعمل الأداة كخدمة مستخدم في systemd. سجّل الدخول إلى Claude أولًا.

<div dir="ltr">

```bash
git clone https://github.com/mohakr28/claude-window-pinger.git
cd claude-window-pinger
claude auth login
./scripts/install-desktop.sh
```

</div>

ولتستمر في العمل بعد تسجيل خروجك:

<div dir="ltr">

```bash
loginctl enable-linger "$USER"
```

</div>

## التثبيت على خادم

نفّذ الأوامر كـ root. ينشئ السكربت مستخدمًا مخصصًا `claude-pinger` وخدمة نظام معزولة، ويثبّت Claude CLI لهذا المستخدم فقط.

<div dir="ltr">

```bash
git clone https://github.com/mohakr28/claude-window-pinger.git
cd claude-window-pinger
./scripts/install-server.sh
/usr/local/sbin/claude-pinger-login
```

</div>

يعرض الأمر الأخير رابطًا، افتحه وسجّل الدخول. تُحفظ جلستك في المجلد الخاص بمستخدم الخدمة فقط.

## الأوامر اليومية

| المهمة | الجهاز الشخصي | الخادم (كـ root) |
|---|---|---|
| متابعة السجل | `journalctl --user -u claude-window-pinger -f` | `journalctl -u claude-pinger -f` |
| موعد البينج التالي | `claude-window-pinger status` | `runuser -u claude-pinger -- env HOME=/var/lib/claude-pinger /usr/local/bin/claude-window-pinger status` |
| إعادة التشغيل بعد الإصلاح | `systemctl --user restart claude-window-pinger` | `systemctl restart claude-pinger` |
| الإزالة الكاملة | `./scripts/uninstall-desktop.sh` | `/usr/local/sbin/claude-pinger-uninstall` |

## التعامل مع الأخطاء

| الحالة | تصرف الأداة |
|---|---|
| لم يُسجَّل الدخول، أو انتهت الجلسة، أو الباقة لا تشمل Claude Code، أو مشكلة في الفوترة أو الحساب | **تتوقف** برمز 78 وتكتب السبب، ولا يعيد systemd تشغيلها |
| تسجيل الدخول بمفتاح API أو حساب Console | **تتوقف** قبل إرسال أي شيء، حتى لا تُحسب تكلفة |
| الرد يشير إلى استخدام رصيد إضافي مدفوع | **تتوقف**، حتى لا يُخصم المزيد |
| بلوغ حد الخمس ساعات أو الحد الأسبوعي | تنتظر موعد إعادة التعيين المذكور في الرد |
| انقطاع الشبكة، أو ضغط الخوادم، أو انتهاء المهلة | تعيد المحاولة بعد 1 و2 و4 و8 دقائق، ثم كل 15 دقيقة |
| النموذج غير متاح | تجرب النموذج الافتراضي للباقة مرة واحدة |
| خطأ غير معروف | الفواصل نفسها، حتى مرة كل ساعة |
| الرد بلا موعد إعادة تعيين | تعيد الفحص بعد ساعة |
| خلل برمجي يسبب تكرارًا | لا أكثر من 12 بينجًا ناجحًا في 24 ساعة |
| تشغيل نسخة ثانية | ترفض العمل |
| إعادة التشغيل أثناء النافذة | تستأنف الانتظار دون بينج إضافي |

تتعرف الأداة على الأخطاء بمطابقة نصوصها، وقد تتغير رسائل CLI. وأي رسالة جديدة تُعامل كخطأ غير معروف، وهو المسار البطيء والآمن.

## العزل على الخادم

الخدمة في [`systemd/claude-pinger.service`](systemd/claude-pinger.service):

- تعمل بمستخدم بلا كلمة مرور ولا صدفة دخول ولا وصول SSH
- تكتب في `/var/lib/claude-pinger` فقط، ولا ترى `/home` أو `/root`
- لا تصل إلى الخدمات المحلية مثل MariaDB وRedis، ما عدا DNS
- لا تستطيع رفع صلاحياتها: `NoNewPrivileges` يمنع `sudo` حتى لو سمحت به قاعدة في sudoers
- محدودة بـ 768 ميغابايت من الذاكرة ونصف نواة معالج

**ما لا يحميه هذا العزل:** جلسة Claude محفوظة على الخادم، فمن يحصل على root يستطيع الوصول إليها. نفّذ `sudo -l -U claude-pinger` لتعرف هل تمنح لوحة الاستضافة كل المستخدمين قواعد `sudo`؛ فالعزل يمنعها داخل الخدمة فقط، وليس في الجلسات الأخرى.

## التطوير

تستخدم الاختبارات CLI وهميًا، فلا تحتاج إلى حساب Claude ولا تستهلك حصة.

<div dir="ltr">

```bash
python3 -m unittest discover -s tests -v
```

</div>

جرى التثبيت على خادم Ubuntu 24.04 مع Claude Code 2.1.318. وعلى جهاز شخصي، جُرّب البينج على Parrot OS مع Claude Code 2.1.309، لكن `install-desktop.sh` نفسه لم يُشغَّل بعد. وهي تقرأ مخرجات `stream-json` من CLI، فقد يؤثر فيها أي تغيير مستقبلي. وإذا اختفى موعد إعادة التعيين، تعيد الفحص مرة كل ساعة.
